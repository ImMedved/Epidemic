# Goal 3 Block C evidence: EngineRuntime/Navigation

Date: 2026-09-21.

This module-local evidence belongs to the four-way final Goal 3 closure pass. Shared canonical freeze registries are intentionally not modified by this block. All IDs below are generated from the supplied final-closure baseline and must be merged by ID after the four independent deltas are combined.

## Responsibility and ownership

Owns navigation tile state/revisions and handle-based budgeted path-query processing over neutral revision, cost, obstacle and backend providers.

## Authoritative state and indexes

Authoritative state is tile registry/dirty work, query records/generations, navigation/result revisions, release/TTL state and privately retained accepted backend/reference results awaiting local publication.

## Public and external contract

Provider/backend failure and exceptions are contained. A successful backend result is retained across local budget/allocation failure and is not rebuilt; purge commits only after all fallible work-list preparation succeeds.

## Lifecycle and cleanup

No module-level Shutdown/startup lifecycle API exists. Query lifecycle is Pending/Running/PartiallyComplete/Completed/Failed/Cancelled/Stale with explicit cancel/release/TTL semantics.

## Limits, counters and identity

Tile/query work respects item and byte budgets; byte admission uses the actual prepared path shape. IDs, generations and revisions are checked for exhaustion before publication.

## Persistence applicability

Navigation exposes no local snapshot/restore API; tile/query state is transient Runtime materialization.
