## Responsibility and ownership

Owns collision-shape/body identity, fixed-step timing, backend synchronization, contact/query publication and retryable transform projection through neutral backend/source/sink interfaces.

## Authoritative state and indexes

Authoritative state is registered shapes, body records/generations, backend-handle ownership, accumulator/fixed-step counters, contact buffer, pending backend cleanup and pending transform projections.

## Public and external contract

Backend creation/simulation/query/contact and transform source/sink failure are contained. Accepted fixed-step prefixes remain committed; sync/projection retry does not resimulate an already accepted backend step. Publication rollback retains cleanup ownership when rollback itself cannot finish.

## Lifecycle and cleanup

Backend initialization and Runtime Shutdown are explicit. Shutdown cleans bodies before referenced shapes, continues independent cleanup best-effort and retries unfinished backend destruction without repeating completed cleanup.

## Limits, counters and identity

Body IDs/generations, backend handle uniqueness, revisions, accumulator/time counters and max_substeps are checked. Raycast normalization is overflow-safe for large finite float directions.

## Persistence applicability

Physics exposes no module-local snapshot/restore surface; physical Runtime state is transient and reconstructed by higher-level composition.
