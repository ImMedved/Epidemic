## Responsibility and ownership

Owns simulation jobs, scheduled tasks, world-memory events, attention/relevance state, abstract facts and proposal queue infrastructure; downstream domain state remains external.

## Authoritative state and indexes

Authoritative state is jobs/generations, task schedule, memory events, attention maps, facts/revision, proposal batches and shutdown state. Successful ExecuteStep result may be retained as private pending accepted state until publication completes.

## Public and external contract

Callback Result failure/exception is contained. A successful ExecuteStep is accepted once and retained across later local staging failure. Named allocation seams prove attention/proposal/work-list failures do not publish partial state.

## Lifecycle and cleanup

Shutdown becomes terminal for new Tick/Schedule/proposal publication as soon as cleanup starts; cancellation/cleanup remain retryable and completed shutdown is idempotent.

## Limits, counters and identity

Job/work budgets, terminal-job/memory/fact/proposal capacities, generated IDs, generations and fact revision have checked boundary behavior.

## Persistence applicability

No module-local snapshot/restore API exists in Goal 3. Whole-engine persistence and ordered restore remain composition/system responsibilities.
