# Документация Epidemic

Этот комплект заменяет разрозненные обзоры, планы заморозки и повторяющиеся списки правил. Пользовательская документация движка теперь имеет одинаковую структуру для двух нижних слоев:

```text
EngineBase/
    README.md
    using_enginebase.md
    modules/

EngineRuntime/
    README.md
    using_engineruntime.md
    modules/
```

`README.md` объясняет назначение слоя, его устройство, границы и место в проекте. Файл `using_*.md` показывает практическое использование из composition root, следующего слоя движка и будущей игры. Подпапка `modules` содержит по одному подробному документу на модуль: модель данных, публичные контракты, жизненный цикл, инварианты, ограничения и точки интеграции.

В корне также находится визионерский документ игры и описание принятого подхода к документации.

Документы EngineBase основаны на `EngineBaseFixed.zip`. Документы EngineRuntime основаны на последнем доступном архиве `EngineRuntimebebe.zip` и на перечисленных после него финальных исправлениях Streaming, Physics, Audio и Simulation. Документ Support намеренно остается предварительным: его окончательная версия должна быть написана после завершения реальной композиции Runtime.
