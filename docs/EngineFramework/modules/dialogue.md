# Dialogue

Status: B07 Goal 4 review. Local module contract only.

Responsibility: owns dialogue/conversation definitions, active and terminal sessions, option use state, consequence execution records and dialogue change history.

Authoritative state: frozen conversation definitions, session records, used-option/repeat state, consequence execution ID generator, revision, journal epoch/sequence and diagnostics. Participant gameplay objects are referenced, not owned.

Dependencies: Framework Foundation and EngineBase Foundation. External collaboration is explicit through participant validation plus `IDialogueConditionResolver` and `IDialogueConsequenceHandler`.

Identity and lifecycle: graph registration validates node/option references, automatic transitions and duplicates before freeze. Sessions validate participants and current nodes. Options follow repeat policy, transitions must target valid nodes, terminal conversations reject invalid continuation, and consequence execution IDs are staged before commit.

Failure and atomicity: resolver/handler failure or exception does not publish an invalid transition. Session, consequence, generator, revision and journal updates are staged and committed together where a mutation spans multiple records. No-op/idempotent terminal behavior is explicit.

Persistence boundary: snapshots include sessions, consequence execution/generator state, revision and journal continuity. Restore validates definitions, participants/references, duplicates and enum/state values before swapping live state; failed restore leaves prior state intact.

Determinism and limits: option and journal observations use deterministic order. Sequence/revision exhaustion is rejected and retained history respects cursor semantics.

Threading contract: synchronous caller-serialized owner with no hidden worker.

Local invariants and tests: `dialogue_tests.cpp` covers graph validation/freeze, participant and resolver paths, option repeat rules, handler failures, terminal transitions, duplicate consequence execution prevention, invalid/stale references, sequence boundaries and snapshot/restore atomicity.
