# Narrative

Status: B07 Goal 4 review. Local module contract only.

Responsibility: owns narrative definitions and runtime state for threads, objectives, beats, storylets, choices, clues/journal entries and consequence executions. Condition resolvers and consequence handlers are explicit ports and do not become authoritative owners.

Authoritative state: frozen definitions, thread/objective/choice runtime records, activated beats, journal/clues, consequence execution/idempotency records, consequence ID generator, revision, change journal/cursor and diagnostics needed for the local contract.

Dependencies: Framework Foundation and EngineBase Foundation. External collaboration is limited to `INarrativeConditionResolver` and `INarrativeConsequenceHandler`.

Identity and lifecycle: definition registration ends at freeze. Threads and objectives have validated allowed/terminal transitions. Choices resolve/cancel/expire once according to repeat policy. Consequence execution IDs are staged from a copied generator and duplicate consequence keys are idempotent.

Failure and atomicity: condition/handler exceptions and retryable/permanent failures are surfaced by the documented consequence state machine. Mutations preflight revision exhaustion and stage multi-container changes before authoritative publication. Failed planning or execution cannot publish a half consequence/journal state.

Persistence boundary: `CaptureSnapshot` persists runtime records, generator, revision and journal continuity. `RestoreSnapshot` validates current-definition references, duplicates, enums, generators, revision and cursor off-state. The B07 `restore.publish` seam is immediately before live container publication and proves failed restore preserves the complete pre-state.

Determinism and limits: event/choice/storylet processing obeys explicit budgets and deterministic ordering. Consequence planning verifies generator capacity before allocating IDs. Bounded history/pruning preserves the latest cursor contract.

Threading contract: synchronous caller-serialized owner with no hidden worker.

Local invariants and tests: `narrative_tests.cpp` and `narrative_choices_storylets_tests.cpp` cover definition freeze, thread/objective lifecycle, choice/repeat behavior, event and storylet budgets, resolver/handler failures, duplicate consequence prevention, journal/cursor behavior, generator/revision boundaries, non-empty/invalid restore and the B07 restore publication seam.
