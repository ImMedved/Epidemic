# World

Status: B07 Goal 4 review. Local module contract only.

Responsibility: owns semantic gameplay-world definitions and records for regions, areas, locations, dynamic features, object placements and world alterations. Public contract: `World/include/Epidemic/GameFramework/World/world.h`; implementation: `World/src/world.cpp`.

Authoritative state: registered world definitions, dynamic feature records, object placements, alterations, spatial/derived indexes, alteration ID generator, module revision and bounded change journal. Runtime world state is not authoritative here.

Dependencies: Framework Foundation plus EngineBase Foundation. No peer gameplay owner is linked directly and there is no direct external backend port.

Identity and lifecycle: definitions are mutable only before `Freeze()`. Alterations are created and changed transactionally, with create/update/remove validation and explicit lifecycle states. Unknown or stale IDs are rejected or treated as documented no-ops. Requested alteration IDs advance the staged generator only on a successful commit.

Persistence boundary: `CaptureSnapshot` persists dynamic authoritative state, generator, revision and journal continuity. `RestoreSnapshot` validates all definitions, enums, references, duplicate IDs, indexes and generator/revision/cursor data off-state, then publishes by swap. Invalid or fallible restore leaves the live world unchanged.

Failure and atomicity: direct feature publication, transaction publication and restore publication are staged before commit. B07 private fault seams exercise all three publication points and verify revision, generator, indexes and journal remain unchanged on failure.

Determinism and limits: externally observable collections and journal reads have deterministic ordering. Journal retention and transaction sizes follow explicit module limits; stale change cursors require a snapshot rather than returning an incomplete delta.

Threading contract: synchronous caller-serialized service with no hidden worker or internal synchronization.

Local invariants and tests: `world_tests.cpp` covers definition freeze/topology, transaction create/update/remove/cancel, requested IDs, invalid enums/references, deterministic spatial state, non-empty and corrupt snapshot restore, stale cursor behavior and the B07 publication-failure seams.
