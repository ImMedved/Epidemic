# Foundation

Status: B01 Goal 4 review. The module is qualified only for local readiness; this document does not claim whole-engine freeze.

Responsibility: common gameplay identities, references, tags, value/time types, monotonic ID allocation, change cursors, type registration and the lightweight `GameplayContext`. Public headers are under `EngineFramework/BaseInfrastructure/Foundation/include/Epidemic/GameFramework/Foundation`.

Authoritative state is confined to explicit value objects and caller-owned registry/generator instances. `MonotonicIdGenerator` owns scope/next state. `StableTypeRegistry` and `GameplayTagRegistry` own registration/freeze state. Derived lookups are registry indexes and tag hierarchy data. `GameplayContext` stores non-owning context pointers and does not create hidden subsystem ownership.

Dependencies: `EngineBase/Foundation` only. No Runtime or peer Framework owner is required.

Identity and lifecycle: invalid IDs use their documented zero/invalid forms. Monotonic generators preserve scope and exhaustion state across snapshot/restore and never wrap into a reusable valid ID. Registries reject duplicate/incompatible registration and reject mutation after freeze. Stale object/part references remain distinguishable through generation-bearing reference values supplied by owners.

Persistence boundary: generator snapshots and value types are local persistence candidates. Framework-wide ordered persistence is Goal 5. Restore validates scope/next continuity before replacing generator state.

Failure and atomicity: validation failures do not modify registry/generator state. Container allocation failure is required to preserve pre-state for registrations. No external side effects exist.

Limits and threading: integer ranges are bounded by their underlying fixed-width representations; generator exhaustion is terminal until an explicit valid restore. Instances are synchronous and caller-serialized; no internal thread ownership is provided.

Local invariants and tests: `foundation_tests.cpp` covers invalid IDs, generator exhaustion/restore, registry duplicate/freeze behavior, tag hierarchy, arithmetic boundaries and pre-state checks.
