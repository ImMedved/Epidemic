# Facts

Status: B01 Goal 4 review. Local module contract only.

Responsibility: typed fact state, typed gameplay events, transactions/batches, subscriber dispatch, retained history/journal cursors, type registration/freeze and snapshot/restore. Public contract: `gameplay_facts.h`.

Authoritative state: current fact records, registered fact/event types, pending submitted batches, sequence/generator state and retained history. Derived state consists of lookup/index structures and dispatch ordering metadata.

Dependencies: Framework Foundation. Codec/compactor/subscriber callbacks are explicit ports and are not authoritative owners.

Lifecycle and identity: fact assert/update/remove transitions are keyed by stable fact identity. Event/fact type registration freezes before steady-state use. Duplicate identities and stale/invalid cursors are rejected by contract. Transactions publish all-or-nothing local state.

Persistence boundary: snapshots cover persistent facts/history required by policy together with generator/sequence/cursor continuity. Invalid snapshots are rejected without replacing live state. Whole-engine participant ordering is Goal 5.

Failure and atomicity: failed transaction staging/commit does not publish half-state. Subscriber failure follows the documented isolation policy and must not corrupt authoritative state. Submitted batches remain owned for retry when local merge/dispatch staging cannot complete.

Limits and threading: retained history is bounded by history policy/compaction decisions. Public mutation is synchronous and caller-serialized; callback reentrancy is constrained by service dispatch semantics.

Local invariants and tests: `facts_tests.cpp` covers fact lifecycle, transaction rollback/commit, event ordering, subscribers, history/cursors, compaction, snapshot roundtrip/validation, retry ownership and publication atomicity.
