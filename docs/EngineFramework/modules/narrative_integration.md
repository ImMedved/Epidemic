# NarrativeIntegration

Status: B07 Goal 4 review. Local integration contract only.

Responsibility: coordinates semantic narrative events, Knowledge-to-Narrative references and the durable local outbox for externally applied narrative consequences. Narrative, Knowledge and SaveGame remain authoritative owners of their own state.

Dependencies: Narrative, Knowledge, SaveGame and EngineBase Foundation. The integration registry and save participant are explicit adapters; this module has no direct Runtime/platform dependency.

Contract registry: narrative event mappings are unique and mutable only before freeze. Duplicate registration is idempotent only for the standard contract set and conflicting event mappings are rejected.

Durable outbox: each narrative consequence execution maps to one stable external operation ID. Duplicate `Execute` is idempotent when the durable record matches, conflicting duplicates are rejected, capacity exhaustion returns retryable backpressure, and only confirmed terminal records may be pruned.

Revision boundary: outbox revision is persisted and therefore exhaustion at `UINT64_MAX` is a hard terminal boundary. Every mutating transition preflights the next revision. Execute, retry, acknowledge, terminal fail and prune never wrap revision to zero and never mutate state when no next revision exists. This closes G4-NARRINT-001.

Publication atomicity: `Execute` fully stages the delivery, invokes the B07 private publication seam, publishes the vector record, and only then commits the authoritative revision. Allocation failure returns retryable failure with the original revision and outbox contents unchanged. This closes G4-NARRINT-002.

Persistence/reconciliation: the save participant validates bounded payload/counts and duplicate execution identities, stages normalized delivery ordering, then atomically restores the outbox. Repeated restore is stable and stale/invalid sections do not mutate the live outbox.

Threading contract: synchronous caller-serialized adapter/outbox with no hidden worker.

Local invariants and tests: `narrative_integration_tests.cpp` covers registry freeze/duplicates, semantic event budgets and idempotence, handler/outbox retry and acknowledgement, capacity, duplicate/corrupt save sections, ordered restore, stable operation IDs, terminal pruning, `TestNarrativeOutboxPublicationAtomicity` and `TestNarrativeOutboxRevisionExhaustion`.
